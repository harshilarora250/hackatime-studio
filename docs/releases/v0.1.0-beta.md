# Hackatime Studio 1.0

A native macOS app for [Hackatime](https://hackatime.hackclub.com) and WakaTime. Studio edits your real `~/.wakatime.cfg`, reads your stats from the real Hackatime API, and manages the VS Code extension. It never tracks time itself.

## Highlights

### Dashboard
Today, this week, this month, your streak, a contribution-style activity graph, top languages and projects, daily goal progress, tracking status and recent sessions. You can rearrange widgets and show or hide them.

<!-- SCREENSHOT: Dashboard, light mode -->
![Dashboard in light mode](SCREENSHOT_DASHBOARD_LIGHT_URL)

### Desktop widgets (new)
**Coding Activity** (small: 8 weeks, medium: 16 weeks) and **Daily Goal** (small, medium) widgets for your desktop. They use the app's look in light and dark mode and work in macOS's tinted widget style. To add them: right-click the desktop → **Edit Widgets…** → **Hackatime Studio**.

<!-- SCREENSHOT: Desktop widgets on the macOS desktop (activity + goal, small and medium) -->
![Desktop widgets](SCREENSHOT_WIDGETS_URL)

> Widgets update whenever Studio refreshes (keep it running, or open it now and then). Your API key never leaves the app.

### Configuration editor
Every verified `wakatime-cli` option, each labelled with the config key it writes. Edits keep your comments and unknown keys, and are written atomically with automatic backups. Changes made by other tools are picked up live.

### Folders & projects
Turn folders into `[projectmap]` and `exclude` rules without writing regexes.

### Editors and diagnostics
- Install and check the Hackatime VS Code extension, with a warning when two extensions would send duplicate heartbeats.
- Diagnostics check your config, API key, `wakatime-cli`, editor setup and recent heartbeats, and suggest a fix for each problem they find.

<!-- SCREENSHOT: Diagnostics page -->
![Diagnostics](SCREENSHOT_DIAGNOSTICS_URL)

### Setup and uninstall
- Guided setup checks your API key with Hackatime before saving it.
- Uninstall can undo only what Studio set up, or remove Hackatime/WakaTime completely.

## Requirements
- macOS 26.5 or later
- A Hackatime account and API key (from [hackatime.hackclub.com/my/settings](https://hackatime.hackclub.com/my/settings))

## Install
1. Download **Hackatime Studio.zip** below and unzip it.
2. Move **Hackatime Studio.app** to `/Applications` and open it.

<!-- ASSET: attach "Hackatime Studio.zip" (notarized build) to this release -->

> Studio is not sandboxed, because it needs to read and write `~/.wakatime.cfg` and `~/.wakatime/`. That's why it's distributed here and not on the Mac App Store.

## Known limitations
- The Hackatime API only exposes **daily** goals; weekly and custom goals aren't available.
- Desktop widgets only show new data after Studio has refreshed.
